HardScript diagnostics have stable codes and a fixed help line. The catalog is
generated from the compiler itself, so it cannot drift from what the compiler
actually emits.

## The ranges

| Range | What lives there |
| --- | --- |
| `HS00xx` | Lexer and parser |
| `HS01xx` | Names, bindings and types |
| `HS02xx` | Semantics: routes, models, middleware |
| `HS03xx` | Codegen and the emitted program |

The [catalog](/docs/errors/catalog) is written by
`npm run docs:errors`, which runs `hard errors --markdown` and turns the result
into a page. It is not written by hand, which is the point: a hand-written error
list is a list that goes stale, and a stale error list is worse than none.

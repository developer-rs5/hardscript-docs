A HardScript program is a flat list of top-level items — imports, a port
declaration, models, middleware, functions, routes, sockets and tests — and
there is no nesting of one file inside another. Modules are the unit of reuse,
and they are brought in by name.

Two facts shape everything else on these pages:

- **`<-` does two things.** In a route or a `calc` body it is the return. In a
  block it is a binding. `total <- 0` binds; `<- { ok: 1 }` returns.
- **There is no `else`.** A conditional that does not match simply falls
  through, and a route falls off the end of its body. The compiler will not
  invent a path for you: [control flow](/docs/language/control-flow) shows the
  pattern this forces, and it is a better one than it looks.
